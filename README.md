# СЕО тела

Локальное desktop-first веб-приложение для учёта питания, тренировок, активности, сна, замеров и динамики веса. Flask обслуживает API и production-сборку React, данные хранятся локально в SQLite.

Новая установка создаёт пустой локальный профиль без продуктов, тренировок, замеров и истории.

## Стек

- Python 3.12 и Flask;
- SQLite;
- React 18, Vite и Tailwind CSS;
- unittest и Playwright.

Docker для локального запуска не требуется.

## Требования

- Windows 10/11;
- Python 3.12;
- Node.js 20 или новее;
- npm.

## Установка

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install
npm run build
```

Локальная база и загруженные изображения создаются в игнорируемых Git каталогах `data/` и `static/uploads/`. Новый профиль не должен получать пользовательские продукты, тренировки, замеры или историю из репозитория.

## Одна кодовая база и локальные данные

Публичная и персональная версии используют один и тот же код. Персональная установка — это обычная локальная копия репозитория, в которой `data/` и `static/uploads/` содержат ваши данные и не отслеживаются Git. Поэтому изменения интерфейса и логики коммитятся и распространяются через Git, а локальная БД, резервные копии и изображения остаются на компьютере.

Новая копия репозитория создаёт пустую БД при первом запуске. `git pull`, переключение веток и изменение исходного кода не должны удалять или заменять локальную БД. Перед переносом установки на другой компьютер скопируйте `data/` и `static/uploads/` отдельно.

## Обычный запуск

Дважды кликни `Запустить СЕО.bat` или выполни:

```powershell
.venv\Scripts\python.exe app.py
```

Приложение откроется по адресу `http://127.0.0.1:5050`.

Для запуска на другом порту:

```powershell
.venv\Scripts\python.exe app.py --port 5070
```

Порты `5060` и `5061` не используются: современные браузеры блокируют их как служебные SIP-порты. Для тихого launcher-скрипта порт также можно задать переменной окружения `CEO_BODY_PORT`.

При первом запуске открой раздел «Стратегия» и укажи название фазы, базовый TDEE, белковый коридор и целевую дельту. Эти значения не поставляются вместе с приложением.

Тихий запуск без окна и автоматического открытия браузера:

```powershell
.venv\Scripts\pythonw.exe app.py --headless
```

## Разработка с автообновлением

Дважды кликни `Запустить разработку.bat` или запусти Flask и Vite отдельно:

```powershell
.venv\Scripts\pythonw.exe app.py --headless
npm run dev
```

Vite откроет интерфейс на `http://127.0.0.1:5173` и будет пересобирать React и стили после сохранения файлов. Flask API продолжит работать на `http://127.0.0.1:5050`.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
npm run lint
npm run build
npm run test:e2e
```

Перед первым запуском Playwright может потребоваться установить Chromium:

```powershell
npx playwright install chromium
```

Тесты обязаны использовать временную БД и не должны изменять `data/ceo_body.db`.

## Данные и резервные копии

- основная база: `data/ceo_body.db`;
- резервные копии: `data/backups/`;
- пользовательские изображения: `static/uploads/`;
- runtime-логи: `logs/` и `data/*.log`.

Эти каталоги не должны попадать в Git. Перед публичным релизом необходимо дополнительно проверить весь отслеживаемый набор файлов и историю Git на персональные данные и сторонние визуальные материалы.

## Автозапуск

Дважды кликни `Установить автозапуск.bat`, чтобы добавить тихий production-запуск Flask в Startup-папку текущего пользователя. Скрипт использует относительный путь проекта, не запускает Vite, не открывает браузер и не показывает окно консоли.

Для удаления созданного ярлыка запусти `Удалить автозапуск.bat`. Повторная установка и повторное удаление безопасны.

## Ограничение ответственности

Расход калорий, TDEE и прогноз изменения веса являются оценками. Приложение предназначено для личного учёта и не заменяет консультацию врача.
