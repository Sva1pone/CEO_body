# Политика безопасности

## Поддерживаемая версия

Исправления безопасности предназначены для последней опубликованной версии и актуальной ветки `main`.

## Сообщение об уязвимости

Не создавайте публичный Issue, если проблема может раскрыть пользовательские данные, позволить чтение или изменение локальных файлов либо привести к выполнению произвольного кода.

Используйте приватное сообщение об уязвимости через раздел **Security → Report a vulnerability** репозитория. Опишите:

- затронутую версию или commit;
- условия воспроизведения;
- возможное влияние;
- минимальный пример без персональных данных;
- предлагаемый способ исправления, если он известен.

Не прикладывайте настоящую `ceo_body.db`, выгруженные Markdown-отчёты, пользовательские изображения, резервные копии, токены, ключи или полные локальные пути. Создайте синтетический пример либо удалите чувствительные сведения.

После проверки информация и исправление могут быть опубликованы согласованно с автором сообщения.
