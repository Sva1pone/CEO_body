# Участие в разработке

Спасибо за интерес к «СЕО тела». Проект открыт для исправлений, улучшений документации и новых идей.

## Перед началом

- проверьте существующие Issues и Discussions;
- для крупного изменения сначала опишите проблему и предлагаемое решение;
- не публикуйте личную базу данных, отчёты, фотографии, логи или другие персональные материалы;
- не добавляйте в исходный код готовые пользовательские стратегии, продукты, тренировки и замеры.

## Локальный запуск

```powershell
git clone https://github.com/Sva1pone/CEO_body.git
cd CEO_body
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm run build
.venv\Scripts\python.exe app.py
```

Локальная SQLite и пользовательские файлы создаются в игнорируемых каталогах. Для разработки и тестов используйте только синтетические данные.

## Проверки

Перед Pull Request выполните:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
npm run lint
npm run build
npm run test:e2e
```

## Pull Request

- делайте изменение небольшим и сфокусированным;
- объясните проблему и выбранное решение;
- перечислите выполненные проверки;
- добавьте или обновите тесты, если меняется поведение;
- укажите, затрагиваются ли схема БД, миграции или пользовательские данные;
- проверьте diff на персональные сведения и случайные бинарные файлы.

Использование ИИ-агентов допустимо, но автор Pull Request обязан самостоятельно проверить код, тесты и последствия изменения. Если ИИ существенно участвовал в подготовке изменения, это можно кратко отметить в описании PR.

Отправляя вклад, вы соглашаетесь распространять его на условиях лицензии MIT этого проекта.
